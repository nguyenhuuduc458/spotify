# 🎵 Musify — Spotify-Inspired Android App (Jetpack Compose)

A modern, elegant music streaming app inspired by Spotify — built with **Jetpack Compose**, **Kotlin**, and best Android development practices. Stream audio, explore playlists, toggle dark/light themes, and enjoy real-time UI interactions in a beautifully designed mobile experience.

## ✨ Features

- 🎨 **Jetpack Compose UI** — Declarative UI design with beautiful theming and smooth animations
- 🎧 **Audio Playback** — Seamless media playback with controls and metadata handling
- 🧠 **MVVM Architecture** — Clean separation of concerns using `ViewModel`, `StateFlow`, and repository pattern
- 💉 **Dependency Injection** — Modular and testable codebase with **Koin**
- 🧭 **Navigation** — Type-safe screen transitions using **Jetpack Compose Navigation**
- 🌗 **Dark & Light Theme** — Fully responsive UI that adapts to system theme
- 🔄 **Real-time UI Updates** — Dynamic state management with `StateFlow` ensures reactive views
- 📦 **Multi-module Architecture** — Scalable codebase with clearly defined boundaries

## 🧑‍💻 Tech Stack

- **Kotlin**, **Jetpack Compose**, **Coroutines**, **Koin**, **StateFlow**, **Media3**, **Accompanist**, **Firebase**
